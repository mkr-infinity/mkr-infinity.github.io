# Mohammad Kaif Raja (@mkr-infinity) — Portfolio v3

> An ultra-modern, scroll-driven 3D animated portfolio built with React 19, Three.js, TypeScript, and Tailwind CSS v4.

---

## ✨ Features & Architecture

- 🌌 **Scroll-Driven 3D Canvas**: Interactive Three.js geometric core and particle nebula that rotates, scales, and morphs camera perspective based on scroll depth and mouse movement.
- 🎯 **Dynamic Reactive Cursor**: Custom cursor with magnetic velocity tracking, hover expansion on interactive elements, click contraction, and touch screen auto-suppression.
- 🔊 **Web Audio Synthesis**: Built-in sound manager providing soft digital feedback on user interactions (toggleable in navbar).
- 📱 **Universal Device Compatibility**: Built for 4K / TV displays, desktops, laptops, tablets, and smartphones with fluid responsive layouts and touch targets.
- 🎵 **Flagship Feature Spotlight (MKR Music)**: Deep showcase of the open-source Android music streaming player with lossless 320 kbps tri-engine playback, synced TTML lyrics, and direct universal APK download.
- 🛠️ **Production Applications Gallery**: Dedicated showcases for **Tailor Master** (customer view & management dashboard), **Revision Master** (v2.0.2 anime study app), **Matrix Solver** (offline Android calculator), and **CalcVerse** (mathematics toolkit).
- 📚 **Technical Documentation Hub**: Featuring **ReadmeHub** (15-theme client-side Markdown generator), **Android Command Cheatsheet**, **Bootloader Unlock Guide**, **GSI Flashing Guide**, and **Windows Activation Guide**.
- 📊 **Accurate Skills Taxonomy**: 10 organized categories with self-assessed estimates, horizontal animated indicators, qualitative labels, and accessible ARIA attributes.
- 📬 **Primary Channel CTA**: Telegram direct link (`https://t.me/mkr_infinity`) alongside verified GitHub, Instagram, and crypto support wallet addresses.

## 🚀 Local Development Setup

This project uses **pnpm** exclusively.

### Prerequisites

- **Node.js**: v18+ (tested on Node v22)
- **pnpm**: v9+ (tested on pnpm v11)

### Setup & Run

1. Navigate to the `v3` directory:
   ```bash
   cd v3
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Start development server:
   ```bash
   pnpm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🏗️ Production Build

To build the static production bundle into `v3/dist`:

```bash
pnpm run build
```

To preview the production build locally:

```bash
pnpm run preview
```
